How the depth band is produced

The active forecast and depth-estimation method will appear here when the dashboard API responds.

6graph nodes
5graph edges
01
Forecast forcing

Open-Meteo hourly precipitation is interpolated into 15-minute amounts. The model receives next-hour rain, a rolling 3-hour total, and a reflectivity proxy calculated from rain; no radar/gauge observation is connected.

02
Runoff and drainage features

Runoff proxy = rainfall × 0.85 imperviousness assumption. Each edge also contributes Manning roughness, slope, cross-section area, catchment area, and effective capacity features.

03
Hydraulic calculation

Manning capacity is adjusted for assumed blockage; runoff above capacity is converted to ponding depth using a 15% contributing fraction and 5,000 m² ponding area.

Qeff = (1/n) × A × Rh^(2/3) × √S × blockage_factorexcess_mm = max((rain_mm × 0.85) − capacity_mmhr, 0)depth_cm = (((excess_mm / 1000) × catchment_m² × 0.15) / 5000 m²) × 100

💡 System Mode Guide: Forecast Data and Demo Simulation

Explanation for SIH Evaluators, Judges & Citizens
🟢 Active Mode: Forecast Model Input
Prototype scope: Dwarka pilot catchment
Forecast coverage: Open-Meteo input is requested for one Dwarka pilot coordinate. No Delhi-wide depth service is configured.
Drainage geometry: The pilot graph is schematic; layout and capacity inputs have not been independently surveyed or validated.
🌦️ Mode 1: Weather Forecast (Default)
How does it work? This mode fetches precipitation forecast-model output from Open-Meteo for the Dwarka pilot coordinate; no local radar or water-level sensor feed is connected.
Result during clear weather: The dashboard shows the rainfall forecast input and the model depth band separately.
🧪 Mode 2: Demo Simulation (Heavy Storm Testing)
Why was this created? Enables evaluators, judges, and citizens to test all advanced system features without waiting for an active monsoon storm.
What is simulated? A fixed synthetic input scenario (65 mm/hr) and formula-derived reflectivity proxy. It is not a real storm, forecast, radar image, or city-wide result:
  • 🧪 Synthetic demo values are shown only for testing the interface.
  • 🚗 Any depth comparison is a model output, not a vehicle safety clearance.
  • 🔀 Route and alert controls may be explored; no agency notification is sent.
